# نصب و اولین صورت‌جلسه

## ۱. پیش‌نیازها

- ویندوز ۱۰/۱۱ (۶۴ بیتی)
- FFmpeg روی `PATH` یا مسیر آن در تنظیمات برنامه
- فضای دیسک: حدود ۹۰۰ MB برای برنامه + حدود ۱٫۷ GB برای مدل‌ها
- اینترنت فقط برای بار اول (دانلود مدل‌ها)؛ پردازش کاملاً محلی است

اگر نسخهٔ نصبی را استفاده می‌کنید، نیازی به نصب پایتون یا .NET نیست (self-contained).

## ۲. نصب

1. `MinuteMate-Setup-0.1.0.exe` را اجرا کنید.
2. مسیر نصب را تأیید کنید (پیش‌فرض: `%LOCALAPPDATA%\Programs\MinuteMate`).
3. در صفحهٔ **AI models** مدل‌ها را تیک بزنید (Whisper turbo و diarization پیش‌فرض روشن‌اند). نصاب دانلود را همان‌جا با درصد پیشرفت انجام می‌دهد؛ لینک دانلود دستی هر مدل هم روی همان صفحه کلیک‌پذیر است.
4. پس از پایان، میان‌بر «MinuteMate» را از منوی شروع باز کنید.

## ۳. اولین اجرا

1. در نوار کناری، وضعیت «موتور آماده» را ببینید؛ اگر قرمز است، «بررسی آمادگی» را بزنید.
2. اگر مدل‌ها موجود نباشند، اولین «شروع رونویسی» مرحلهٔ **دانلود مدل‌ها** را با درصد پیشرفت نشان می‌دهد (فقط بار اول). با دکمهٔ توقف می‌توانید لغو کنید و بعداً ادامه دهید.
3. فایل صوتی را انتخاب کنید (mp3/wav/m4a)، تعداد گویندگان را بگذارید و «شروع رونویسی» را بزنید.
4. خروجی‌ها در پوشهٔ جلسه ظاهر می‌شوند:
   - `01_raw_transcript.txt` — متن خام
   - `02_diarized_cleaned_transcript.md` — متن با تفکیک گویندگان (هشدار هم‌پوشانی در صورت وجود)
   - `03_official_meeting_minutes.md` — صورت‌جلسه (اگر فعال باشد)
   - `*.srt` و `*.segments.json`

## ۴. تنظیمات مهم

- **پوشهٔ جلسات**: محل ذخیرهٔ جلسات و تاریخچه.
- **پوشهٔ مدل‌ها**: اگر مدل‌ها را دستی دانلود کرده‌اید، اینجا مسیر بدهید؛ خالی یعنی `models/` کنار موتور.
- **دستگاه**: `auto` فقط وقتی CUDA واقعاً قابل استفاده باشد (کتابخانه‌های GPU نصب شده) از آن استفاده می‌کند و در غیر این صورت روی CPU می‌ماند. نصاب CUDA را همراه ندارد؛ نصب اختیاری در `README-Models.md` بخش ۲.۶.
- **FFmpeg**: اگر در `PATH` نیست، مسیر کامل `ffmpeg.exe` را وارد کنید.
- **افزودن پرووایدر / کلید API**: نصاب یک فایل `.env` خام (بدون کلید) کنار `MinuteMate.exe` می‌گذارد. آن را با Notepad باز کنید و مثلاً `GROQ_API_KEY=...` را پر کنید؛ چند کلید را با کاما جدا کنید. این فایل با به‌روزرسانی یا حذف برنامه پاک نمی‌شود. مسیرهای جایگزین: `%LOCALAPPDATA%\MinuteMate\.env` یا پوشهٔ جاری.

## ۵. رفع اشکال سریع

| نشانه | راه‌حل |
| :--- | :--- |
| «موتور پیدا نشد» | تنظیمات ← مسیر پایتون یا sidecar؛ یا `engine\minutemate-engine.exe` را کنار برنامه بگذارید |
| «مدل‌ها ناقص» | «بررسی آمادگی» و سپس شروع رونویسی (دانلود خودکار) یا `python -m minutemate models download` |
| خطای `cublas64_12.dll` | درایور NVIDIA را به‌روز کنید؛ موتور خودکار به CPU برمی‌گردد |
| خروجی خالی/هذیان | `--beam-size` بالاتر، زبان صریح `fa`، و کیفیت صدای ورودی را بررسی کنید |

جزئیات بیشتر: `docs/03-operations/troubleshooting.md` و `docs/03-operations/setup-windows.md`.
