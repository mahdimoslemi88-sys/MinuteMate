## ۱. نگاه اجمالی

MinuteMate دو مؤلفهٔ مستقل است که با یک **قرارداد خط‌محور متنی** به هم وصل می‌شوند:

```
┌──────────────────────────────┐        job JSON (stdin)        ┌───────────────────────────┐
│  MinuteMate Desktop (.NET 8) │ ─────────────────────────────▶ │  MinuteMate Engine (Py)   │
│  WPF · MVVM · EngineClient   │ ◀───────────────────────────── │  faster-whisper + sherpa  │
└──────────────────────────────┘      NDJSON events (stdout)    └───────────────────────────┘
              │                                                              │
              │ باز کردن/نمایش                                               │ فایل‌ها
              ▼                                                              ▼
        %LOCALAPPDATA%\MinuteMate  ◀──────── آرتیفکت‌ها ────────────  data/sessions/<id>/out
```

**چرا این مرز؟**

| دلیل | توضیح |
| :--- | :--- |
| زبان‌های متفاوت، ابزارهای متفاوت | موتور به اکوسیستم پایتونی (PyTorch/ONNX/CTranslate2) نیاز دارد؛ UI به WPF |
| مقاومت در برابر خرابی | کرش UI موتور را نمی‌کشد و برعکس؛ پروسهٔ موتور قابل kill مستقل است |
| تست‌پذیری | موتور بدون UI تست می‌شود (CLI + NDJSON) و UI بدون موتور (fixtures) |
| جایگزینی‌پذیری | هر UI دیگری (CLI، وب، سرویس) می‌تواند همان قرارداد را مصرف کند |

## ۲. اجزا

| جزء | فناوری | مسئولیت | محل |
| :--- | :--- | :--- | :--- |
| Engine | Python 3.10+ | پیش‌پردازش، تفکیک گوینده، رونویسی، ادغام، پالایش و تولید خروجی | `engine/minutemate` |
| EngineClient | C# (.NET 8) | پیدا کردن موتور، اجرای پروسه، سریال‌سازی job، پارس رویداد، لغو | `desktop/src/MinuteMate.EngineClient` |
| Core | C# (.NET 8) | قراردادها، مسیرهای داده، تنظیمات، تهی‌سازی JSON | `desktop/src/MinuteMate.Core` |
| App | WPF (.NET 8) | UI، ViewModel، دیالوگ فایل، تم | `desktop/src/MinuteMate.App` |
| Models | فایل‌های ONNX + CTranslate2 | وزن‌های ASR و diarization | `models/` (junction) |
| Data | فایل‌سیستم | جلسات، بنچمارک، خروجی‌ها | `data/` ⏳ M2 |

## ۴. تصمیم‌های معماری (ADR خلاصه)

| تصمیم | جایگزین رد‌شده | دلیل |
| :--- | :--- | :--- |
| NDJSON روی stdout به‌جای چاپ آزاد | لاگ متنی ساده | ماشین‌خوان، پسوندپذیر، جدا از لاگ (stderr) |
| اجرای موتور به‌صورت پروسه (sidecar) | کتابخانهٔ مشترک/P-Invoke | جداسازی وابستگی‌های سنگین پایتون از UI |
| ثبت مدل‌ها در `registry.py` | مسیرهای hardcode | یک منبع حقیقت برای مسیر/حجم/لینک دانلود |
| junction برای `models/` | کپی ۱.۶GB | صفر هزینهٔ دیسک و استفادهٔ مجدد از دانلود موجود |
| پالایش متن فارسی در موتور | انجام در UI/LLM | تکرارپذیری و تست‌پذیری در پایتون |
| صورت‌جلسه با LLM در مرحلهٔ جدا (`minutes`) | ادغام در مرحلهٔ ASR | امکان اجرای آفلاین و ارزیابی مستقل ⏳ M3 |

## ۵. مرزها و قواعد

1. **موتور هیچ‌گاه به UI وابسته نیست**؛ UI فقط مصرف‌کنندهٔ قرارداد است.
2. **موتور هیچ‌گاه به شبکه وابسته نیست** (به‌جز `models download` که صریحاً فراخوانی می‌شود).
3. **UI منطق پردازش صوتی ندارد**؛ فقط ارکستریشن و نمایش.
4. **قرارداد نسخه‌دار است**: هر تغییر در فیلدها یا نام فایل‌های خروجی نیازمند به‌روزرسانی هم‌زمان دو طرف و این اسناد است.

| :--- | :--- | :--- |
