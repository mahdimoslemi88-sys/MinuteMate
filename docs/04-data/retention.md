## ۱. طبقهٔ داده و حساسیت

| طبقه | نمونه | حساسیت | پیش‌فرض |
| :--- | :--- | :--- | :--- |
| مدل‌ها | `models/**` | عمومی (لایسنس‌دار) | بازتولیدشدنی؛ خارج از پشتیبان |
| دادهٔ خام | `raw/` | **محتملاً حساس** (صدای افراد) | نگهداری بلندمدت، رمزنگاری درایو |
| فایل‌های میانی | `work/` | حساس | قابل حذف، بازتولیدشدنی |
| خروجی نهایی | `out/` | محتملاً حساس (صورت‌جلسه) | نگهداری بلندمدت |
| بنچمارک | `benchmarks/**` | فقط با رضایت صریح | ناشناس‌سازی الزامی |

## ۲. سیاست نگهداشت پیشنهادی

| داده | مدت نگهداری | اقدام پس از آن |
| :--- | :--- | :--- |
| `work/*.wav` میانی | ۳۰ روز | حذف (بازتولیدشدنی) |
| `work/*.json` (segments/speakers) | ۹۰ روز | فشرده‌سازی سپس حذف |
| `raw/` | مطابق سیاست سازمان (پیش‌فرض: ۱ سال) | آرشیو آفلاین یا حذف با تأیید مالک |
| `out/` نهایی | دائمی (تا زمانی که نسخهٔ نهایی است) | آرشیو |
| `benchmarks/` | دائمی | — |
| `tmp/` | هر لحظه | حذف خودکار در شروع اجرا |

فرمان‌های اجراشده (M2):

```powershell
python -m minutemate data prune --older-than 30d --target work
python -m minutemate data prune --older-than 90d --target work --keep-transcripts
python -m minutemate data archive --session 2026-10-19-haftegi --delete   # فشرده‌سازی work/ به work.zip
python -m minutemate data list                                            # بازسازی data/index.json
```

## ۳. حریم خصوصی

1. **آفلاین‌بودن پیش‌فرض:** موتور هیچ داده‌ای را بدون اقدام صریح کاربر به بیرون نمی‌فرستد؛ تنها استثنا دانلود مدل و (در M3) فراخوانی LLM که باید در تنظیمات با هشدار روشن باشد.
2. **رضایت ضبط:** مسئولیت رضایت اعضای جلسه بر عهدهٔ کاربر است؛ `docs/06-product/faq.md` و `docs/03-operations/privacy.md`.
3. **ناشناس‌سازی بنچمارک:** پیش از هر اشتراک‌گذاری، نام‌ها در متن و RTTM با `گوینده N` جایگزین شوند.
4. **لاگ‌ها:** `%LOCALAPPDATA%\MinuteMate\logs` و `--log-level DEBUG` نباید مسیرهای حساس یا متن جلسه را در خود داشته باشند (بازبینی در M1 برای پاک‌سازی مسیرها).
5. **حذف داده:** «حذف جلسه» باید `raw/`, `work/`, `out/`, `session.json` و ورودی نمایهٔ جست‌وجو را یک‌جا پاک کند.

## ۴. پشتیبان‌گیری

| چیست | چگونه | چرا |
| :--- | :--- | :--- |
| `data/sessions/*/raw` و `out` | پشتیبان افزایشی روزانه (فشرده) | دادهٔ اصلی برگشت‌ناپذیر |
| `session.json` | همراه جلسه | بازسازی ساختار و فراداده |
| `data/index.json` | بازتولیدشدنی (اسکن دوباره) | لازم نیست در پشتیبان |
| `models/**` | نه (فقط فهرست + `models verify`) | عظیم و بازتولیدشدنی |
| `data/benchmarks` | پشتیبان کامل | مقایسه‌پذیری تاریخی |

بازیابی: بازگردانی `sessions/<id>/` کافی است؛ اگر `work/` نبود، اجرای مجدد پایپ‌لاین آن را بازتولید می‌کند.

## ۵. خارج از git

`.gitignore` این پوشه‌ها را نادیده می‌گیرد: `data/sessions/**`, `data/benchmarks/{audio,truth,reports}/**`, `data/exports/**`, `data/tmp/**`, `models/`, `scratch/`, `output/`, همهٔ فایل‌های صوتی/ویدیویی. آنچه **باید** در git بماند: `data/README.md`, `data/.gitkeep`, `docs/**`, `session.json` نمونهٔ مستندات.

## ۶. بودجهٔ دیسک

| مورد | یک جلسهٔ ۹۰ دقیقه‌ای |
| :--- | :--- |
| صدا ورودی | ۵۰–۱۵۰ MB (بسته به فرمت) |
| WAV میانی (۱۶kHz) | ~۱۷۳ MB |
| JSON میانی | ۲–۸ MB |
| خروجی‌های نهایی | < ۱ MB |
| **جمع** | **~۲۵۰–۳۵۰ MB** |

با حذف `work/` پس از استخراج خروجی‌ها: ~۶۰–۱۵۰ MB برای هر جلسه.
