# حریم خصوصی، لاگ‌ها و مجوزها

## ۱. چه چیزی در لاگ‌ها نوشته می‌شود؟

- رویدادهای مرحله (`stage`)، خطاها، مسیر فایل ورودی/خروجی، نام مدل‌ها و دستگاه.
- **متن جلسه، محتوای رونویسی و کلید API در لاگ‌ها نوشته نمی‌شوند.**
- مسیرها ممکن است نام کاربر ویندوز را داشته باشند؛ قبل از ارسال لاگ برای پشتیبانی، مسیرها را پاک‌سازی کنید.
- لاگ هر اجرا در `<logs>/<jobId>/stdout.ndjson` و `stderr.log` است و طبق `docs/04-data/retention.md` پاک می‌شود.

## ۲. کلید LLM

- کلید فقط از متغیر محیطی (`MINUTEMATE_LLM_API_KEY` یا `apiKeyEnv`) خوانده می‌شود و در job/مانیفست/لاگ ذخیره نمی‌شود.
- اگر provider `none` باشد، هیچ درخواست شبکه‌ای برای صورت‌جلسه ارسال نمی‌شود.

## ۳. رضایت ضبط

مسئولیت گرفتن رضایت اعضای جلسه بر عهدهٔ کاربر/سازمان است. MinuteMate فایل را فقط روی همان رایانه پردازش می‌کند (به‌جز صورت‌جلسهٔ LLM که در صورت فعال بودن به سرویس انتخابی شما ارسال می‌شود).

## ۴. مجوز مدل‌ها

مدل‌ها همراه نصاب منتشر نمی‌شوند و در اولین اجرا دانلود می‌شوند؛ مسئولیت رعایت مجوز هنگام بازتوزیع آفلاین با شماست.

| مدل | منبع | مجوز اعلام‌شده |
| :--- | :--- | :--- |
| Whisper Large-v3-Turbo (بازتوزیع `deepdml/faster-whisper-large-v3-turbo`) | HuggingFace | Whisper اصلی MIT؛ مجوز دقیق بازتوزیع باید پیش از انتشار تجاری بازبینی شود |
| PyAnnote Segmentation 3.0 (بستهٔ sherpa-onnx) | GitHub `k2-fsa/sherpa-onnx` | MIT |
| 3D-Speaker CAM++ | GitHub `k2-fsa/sherpa-onnx` | Apache-2.0 |
| WeSpeaker ResNet34-LM | GitHub `k2-fsa/sherpa-onnx` | Apache-2.0 |

> این جدول یادداشت عملیاتی است، نه مشاورهٔ حقوقی. پیش از انتشار عمومی، متن مجوز هر مخزن را دقیق بخوانید.
