# مجموعهٔ طلایی ارزیابی (Benchmark)

| وضعیت | آخرین به‌روزرسانی | مالک |
| :--- | :--- | :--- |
| فعال (M4a) | 1405-07-28 | Quality |

این پوشه نمونه‌های ثابت برای سنجش WER/CER/DER/JER و RTF را نگه می‌دارد. خود صدا در git نیست؛ فقط `registry.json`، متن/برچسب مرجع و گزارش‌ها کامیت می‌شوند.

## ۱. چیدمان

```
data/benchmarks/
├── registry.json          # فهرست نمونه‌ها (کامیت می‌شود)
├── audio/                 # WAV های محلی (gitignore)
├── truth/                 # متن مرجع + RTTM (کامیت می‌شود)
├── reports/               # گزارش‌های .md/.json (کامیت می‌شود)
└── work/                  # خروجی موتور (gitignore)
```

## ۲. اجرا

```powershell
# اجرای کامل روی همهٔ نمونه‌ها + گزارش خودکار
python scripts\evaluate.py --registry data\benchmarks\registry.json --run-all

# فقط ارزیابی خروجی‌های موجود (بدون اجرای موتور)
python scripts\evaluate.py --hyp-dir data\benchmarks\work\mm19-0062

# فقط یک نمونه، با beam بالاتر
python scripts\evaluate.py --sample mm19-0062 --run-all --beam-size 5
```

گزارش پیش‌فرض: `data/benchmarks/reports/<تاریخ>-<device>-<compute>.md` و همان مسیر با `.json`.

## ۳. نمونهٔ فعلی: `mm19-0062`

- منبع: برش دقیق `62.0–92.0` ثانیه از `../meeting-text/output/session_20261019_16k_mono.wav`.
- ماهیت: جلسهٔ واقعی، صدای دور (far-field)، یک گوینده در این پنجره.
- **متن مرجع فعلی «پیش‌نویس» است:** خروجی ASR با `beam_size=5`، نه رونویسی انسانی. عدد WER محاسبه‌شده با آن، فقط برای مقایسهٔ نسبی مدل‌ها/پارامترها معتبر است.
- **RTTM فعلی هم موقتی است:** از نوبت‌های دیاریزیشن جلسهٔ مبدأ و با جابه‌جایی `-62s` ساخته شده است. موتور در این پنجره تا حدود ۱۶ ثانیه گفتار می‌شنود، ولی منبع تا ۱۲.۲۱۳ ثانیه نوبت دارد؛ بنابراین DER فعلی شامل «miss» واقعی/خطای منبع است.
- برای رسمی‌شدن: متن را با گوش دادن اصلاح کن، مرزهای گفتار را دستی بزن، سپس `truthStatus` را در `registry.json` به `human` تغییر بده و `--strict-truth` را در CI اجرا کن.

## ۴. افزودن نمونه

1. صدا را در `audio/` بگذار (یا فقط مسیر نسبی را ثبت کن؛ صدا کامیت نمی‌شود).
2. متن مرجع را در `truth/<id>.txt` و در صورت نیاز RTTM را در `truth/<id>.rttm` بنویس.
3. یک شیء در `samples` اضافه کن: `id`, `stem`, `audio`, `durationSeconds`, `language`, `speakers`, `truthStatus`, `truthText`, `truthRttm`.
4. اگر مرجع انسانی نیست، `truthStatus` را `draft` بگذار و دلیلش را در `truthSource` بنویس.

## ۵. قواعد

- هر عدد کیفیت باید یا از این مجموعه بیاید یا صریحاً «هدف» علامت بخورد.
- تغییر مدل ASR/دیاریزیشن بدون گزارش جدید در `reports/` پذیرفته نیست.
- صدا، `work/` و فایل‌های موقت هرگز کامیت نمی‌شوند.
