# لایهٔ داده (Data)

| وضعیت | آخرین به‌روزرسانی | مالک |
| :--- | :--- | :--- |
| طرح‌ریزی‌شده (M2) با ساختار فعلی در حال استفاده | 1405-07-27 | Data |

این پوشه محل زندگی **داده‌ها**ست: مدل‌ها، جلسات، بنچمارک‌ها و خروجی‌های نهایی. کد در `engine/` و `desktop/` زندگی می‌کند و داده در `data/`.

> **قاعدهٔ طلایی:** هیچ فایل حجیمی (صدا، ویدیو، مدل، خروجی) وارد git نمی‌شود. ساختار (پوشه‌ها، `.gitkeep`، `README`، `session.json` سبک) بله.

## ۱. چیدمان

```
data/
├── models/            ← می‌تواند junction به پوشهٔ مدل‌های موجود باشد (پیش‌فرض فعلی: <repo>/models)
├── sessions/          ← یک پوشه برای هر جلسه
│   └── <YYYY-MM-DD>-<slug>/
│       ├── raw/            فایل اصلی صدا/ویدیو (تغییرناپذیر)
│       ├── work/           فایل‌های میانی: *_16k_mono.wav, *.segments.*, *.speakers.*
│       ├── out/            خروجی‌های تحویلی: 01_…, 02_…, 03_…, 04_…
│       └── session.json    manifest جلسه
├── benchmarks/        ← مجموعهٔ ارزیابی
│   ├── audio/              نمونه‌های صوتی مرجع
│   ├── truth/              متن مرجع و برچسب گوینده
│   ├── reports/            گزارش‌های WER/DER به‌ازای هر اجرا
│   └── registry.json       فهرست نمونه‌ها و شرایط تست
├── exports/           ← بستهٔ نهایی برای سازمان: docx/pdf/csv
└── tmp/               ← موقت، هر لحظه قابل حذف
```

## ۲. وضعیت فعلی در برابر هدف

| مورد | اکنون | هدف (M2) |
| :--- | :--- | :--- |
| محل خروجی | `--out-dir` مسطح (پیش‌فرض `output/`) + `scratch/` | `data/sessions/<id>/{work,out}` |
| manifest | ندارد | `session.json` با `schemaVersion` |
| تفکیک دادهٔ خام/کاری/تحویلی | ندارد | `raw/` ، `work/` ، `out/` |
| آرشیو/پاک‌سازی | دستی | `minutemate data prune` + سیاست نگهداشت |
| نمایهٔ جست‌وجو | ندارد | `data/index.json` |

تا زمان M2، خروجی‌های فعلی در `output/` و `scratch/` می‌مانند و همان‌ها در `.gitignore` هستند.

## ۳. اتصال ابزارها به داده

| ابزار | تنظیم |
| :--- | :--- |
| موتور (مدل‌ها) | `--models-dir` یا `MINUTEMATE_MODELS_DIR` یا `<repo>/models` |
| موتور (خروجی) | `--out-dir` (اکنون) ⇒ `--session-dir` (M2) |
| دسکتاپ | `MINUTEMATE_DATA_DIR` (پیش‌فرض `%LOCALAPPDATA%\MinuteMate`) |
| بنچمارک | `data/benchmarks/registry.json` |

## ۴. قواعد نام‌گذاری

| چیز | قاعده | نمونه |
| :--- | :--- | :--- |
| پوشهٔ جلسه | `YYYY-MM-DD-<slug>` (تاریخ میلادی، slug لاتین کوچک) | `2026-10-19-haftegi` |
| فایل خام | نام اصلی + بدون تغییر محتوا | `raw/جلسه هفتگی.mp3` |
| فایل میانی | `<stem>_16k_mono.wav`, `<stem>.segments.json` … | — |
| خروجی نهایی | پیشوند عددی ثابت `01_…`, `02_…`, `03_…`, `04_…` | — |
